# Базовые правила проекта

> Автоопределение ограничено: исходный код пока отсутствует. Ниже стартовые безопасные соглашения для MVP.

## Соглашения об именовании
- Файлы: `kebab-case`.
- Переменные: `camelCase`.
- Функции: `camelCase`.
- Классы: `PascalCase`.

## Структура модулей
- `src/http/` — HTTP-роуты и middleware.
- `src/integrations/` — клиент внешнего календарного сервиса.
- `src/ical/` — формирование/валидация iCal-ответа.
- `src/config/` — загрузка и валидация конфигурации.

## Обработка ошибок
- Внутри интеграций: нормализация ошибок внешнего API в внутренние типы ошибок.
- На HTTP-уровне: маппинг ошибок в стабильные статус-коды и безопасные сообщения.

## Логирование
- Структурированные логи с уровнями (`debug`, `info`, `warn`, `error`).
- Никогда не логировать секреты (`password`, `token`, `Authorization`, cookie).
